12. (9.11.2026) "The file can't be found." dialogs (CoreServicesUIAgent, no file name) at every relaunch of v2 to v5. Cause: I ran `relaunch.swift <bundle id> "Agent Manager (Mantra)"`, the app NAME where the tool wants the full app PATH, so its `openApplication` asked LaunchServices to open a path that does not exist; and then I opened the app a second time myself after replacing the bundle under it. The Info.plist, the icon and the Resources were fine, the app opens nothing at launch. Fix: (1) always pass the full path; (2) the new `--no-open` flag of relaunch.swift only quits the old copy; (3) install atomically: ditto to a stage dir, codesign it there, `ditto` to /Applications/.tmp-AgentManager.app, `mv` over the old bundle; (4) ONE `open -g -a "/Applications/Agent Manager (Mantra).app"` after the move. Verified 9.11.2026: CoreServicesUIAgent window count 0 before and 0 after.
13. (9.11.2026, v7) A BUSY session shows the model of its CURRENT task after its name, in orange parentheses (Sessions view and status bar), tooltip = source. Order: the router's latest pick for the session (~/.cache/mantra-bar/<id>.router.json, mode gate or auto and a pick), else the model id of the last main-thread request in the transcript tail, else the status line's model, else settings. A router in mode off has no pick, so the transcript's real model is shown. Workers of a busy session are listed with the model from their .meta.json ("sonnet" etc.; "model unknown" when the spawn did not set one). Limit: the router pick is per prompt; a subagent spawned inside a turn runs on its own model, shown only in the workers line.
